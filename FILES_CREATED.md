## 🚀 Getting Started

### 1. Install Dependencies
```bash
cd streak-maintainer
npm install
```

### 2. Firebase Setup
Follow `FIREBASE_SETUP.md`:
- Create Firebase project
- Enable authentication
- Create Firestore database
- Get credentials
- Add to `.env` file

### 3. Start Development
```bash
npm run dev
```

### 4. Build Production
```bash
npm run build
```

### 5. Deploy
Follow `DEPLOYMENT.md`:
- Firebase Hosting (recommended)
- Netlify
- Vercel
- Custom server
